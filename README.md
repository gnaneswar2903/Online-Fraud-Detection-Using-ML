## 📊 Dataset

The dataset contains information about online payment transactions.

### Attributes include:

- Transaction Type
- Amount
- Old Balance Sender
- New Balance Sender
- Old Balance Receiver
- New Balance Receiver
- Fraud Label

Target Variable:

- **0 → Legitimate Transaction**
- **1 → Fraudulent Transaction**
